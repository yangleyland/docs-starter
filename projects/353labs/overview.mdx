The `353labs` repository holds C++ coursework for a computer networks course. It contains 14 weekly labs (`lab1` to `lab14`) and 5 programming assignments (`pa1` to `pa5`). The work builds from a basic TCP echo server to a multi-node overlay network with reliable data transfer.

## Repository layout

Each lab or assignment lives in its own top-level directory. Directories are self-contained, so each one has its own `Makefile` and its own copy of the shared helper libraries.

| Directory | Contents |
|-----------|----------|
| `lab1` to `lab14` | Weekly lab source, `.script` transcripts, and a `labNdata/` folder with test data and notes |
| `pa1` | Maze solver |
| `pa2` | HTTP server and client |
| `pa3` | Multithreaded, throttled HTTP server |
| `pa4` | Overlay network node with link-state routing |
| `pa5` | Overlay network node with forwarding, traceroute, and reliable data transfer |

## Build requirements

- `g++` with C++11 support.
- OpenSSL development libraries. Several targets link with `-lcrypto`.
- `tmux` and `tcsh`. The test scripts in each `*data/` folder use them.

All `Makefile` files compile with these flags:

```bash
g++ -g -Wall -std=c++11 -DLOCALHOST=\"127.0.0.1\"
```

## Build a target

Run `make` with the target name from inside the directory.

```bash
cd pa3
make pa3
```

Run `make clean` to remove binaries and object files.
