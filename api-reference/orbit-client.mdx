---
title: 'Orbit API client'
description: 'Configure the Orbit API TypeScript client with your API key and base URL, then list projects with cursor pagination or fetch a single project by its ID.'
---

The Orbit API client is a TypeScript class, `OrbitClient`, that wraps requests to the Orbit API. It sends your API key with every request and parses each JSON response for you.

## Create a client

Pass an options object to the `OrbitClient` constructor.

```typescript
const client = new OrbitClient({
  apiKey: process.env.ORBIT_API_KEY,
});
```

### Options

<ParamField body="apiKey" type="string" required>
  Your Orbit API key. The client sends it in the `Authorization` header of every request.
</ParamField>

<ParamField body="baseUrl" type="string" default="https://api.orbit.example.com/v1">
  The base URL for API requests. Set it to point the client at a different Orbit API host.
</ParamField>

## Authentication

The client authenticates with a Bearer token. Every request includes this header:

```http
Authorization: Bearer <apiKey>
```

## Methods

### listProjects

Lists projects, one page at a time.

```typescript
const firstPage = await client.listProjects({ limit: 20 });
```

To fetch the next page, pass the cursor value the API returned with the previous page:

```typescript
const nextPage = await client.listProjects({ limit: 20, cursor: nextCursor });
```

The options object is optional. Call `client.listProjects()` with no arguments to fetch the first page with the default page size.

<ParamField body="limit" type="number" default="50">
  The maximum number of projects to return. The client always sends this value, using 50 when you omit it.
</ParamField>

<ParamField body="cursor" type="string">
  The cursor for the page to fetch. The client sends it only when you provide it.
</ParamField>

The method sends `GET /projects?limit=<limit>&cursor=<cursor>` to your base URL, with the same `Authorization` header as every other request.

It returns a promise that resolves to the parsed JSON response body, typed as `unknown`. Like `getProject`, the method does not check the HTTP status code.

### getProject

Fetches a single project by its ID.

```typescript
const project = await client.getProject('proj_123');
```

<ParamField path="projectId" type="string" required>
  The ID of the project to fetch.
</ParamField>

The method sends `GET /projects/{projectId}` to your base URL. With the default base URL, that is `https://api.orbit.example.com/v1/projects/{projectId}`.

It returns a promise that resolves to the parsed JSON response body, typed as `unknown`. The method does not check the HTTP status code, so a JSON error response resolves like a successful one instead of throwing.
