## Glossary and daily guides

### New features

- **Glossary**: Look up core docs terms such as `docs.json`, navigation, anchors, frontmatter, and snippets. See the [glossary](/glossary).
- **Daily dog breed profiles**: Read a new breed profile each day, including [Chihuahua](/dogs-2026-11-03-0701), [Beagle](/dogs-2026-11-04-0700), [Dachshund](/dogs-2026-11-05-0700), [Labrador Retriever](/dogs-2026-11-06-0700), [Poodle](/dogs-2026-11-07-0700), [German Shepherd](/dogs-2026-11-08-0700), [Bulldog](/dogs-2026-11-09-0700), [Rottweiler](/dogs-2026-11-10-0700), [Doberman Pinscher](/dogs-2026-11-11-0700), [Pug](/dogs-2026-11-12-0700), [Shih Tzu](/dogs-2026-11-13-0700), and [Boxer](/dogs-2026-11-14-0700). Start from [Types of dogs](/dogs).
- **Daily Star Wars guides**: Explore a new guide each day covering factions, planets, starships, droids, bounty hunters, creatures, and the Force. Browse from the [Star Wars overview](/star-wars), or start with the latest, [November 13](/star-wars-2026-11-13-1602).
</Update>
