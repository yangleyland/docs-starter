<Update label="Nov 18, 2026" tags={["Added"]}>
## Glossary, dog breeds, and daily Star Wars guides

### New features

- **Glossary**: Look up five core terms on the new [glossary](/glossary) page.
- **Dog breed profiles**: Read 16 new breed profiles, including the Saint Bernard, Great Dane, Pembroke Welsh Corgi, Australian Shepherd, and Boxer. Start from [Types of dogs](/dogs).
- **Star Wars guides**: Browse a new guide each day, covering topics like the Rebel Alliance, starships, bounty hunters, and the Clone Wars. See the [Star Wars overview](/star-wars).
</Update>
