<Update label="Nov 26, 2026" tags={["Added"]}>
## Glossary, new dog breeds, and daily Star Wars guides

### New features

- **Glossary**: Look up five core documentation terms on the new [Glossary](/glossary) page.
- **24 new dog breed profiles**: Browse new breeds including the Beagle, Chihuahua, Dachshund, Labrador Retriever, Poodle, Vizsla, and Weimaraner. Start from the [Dogs](/dogs) page.
- **Daily Star Wars guides**: Find a new guide almost every day covering the Sith, the Jedi Order, the Rebel Alliance, starships, planets, and droids. Start from the [Star Wars](/star-wars) page.
</Update>
