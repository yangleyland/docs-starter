## Glossary, daily dog breeds, and daily Star Wars pages

### New features

- **Glossary**: Look up core terms such as `docs.json`, navigation, and snippets on the new [Glossary](/glossary) page.
- **Daily dog breed profiles**: Read a new breed profile each day, including [Chihuahua](/dogs-2026-11-03-0701), [Beagle](/dogs-2026-11-04-0700), [Labrador Retriever](/dogs-2026-11-06-0700), [Pug](/dogs-2026-11-12-0700), and [Great Dane](/dogs-2026-11-17-0700). See the [Types of dogs](/dogs) overview.
- **Daily Star Wars pages**: Catch a new Star Wars page each day, from [Nov 3](/star-wars-2026-11-03-1601) to [Nov 16](/star-wars-2026-11-16-1603). See the [Star Wars overview](/star-wars).
</Update>
