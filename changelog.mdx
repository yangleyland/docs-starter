## Glossary, dog breed profiles, and Star Wars guides

### New features

- **Glossary**: Look up core docs terms such as docs.json, navigation, anchors, frontmatter, and snippets. See the [glossary](/glossary).
- **Dog breed profiles**: Browse new breed pages with temperament, origin, coat, and quick facts. This release adds the [Chihuahua](/dogs-2026-11-03-0701), [Beagle](/dogs-2026-11-04-0700), [Dachshund](/dogs-2026-11-05-0700), [Labrador Retriever](/dogs-2026-11-06-0700), [Poodle](/dogs-2026-11-07-0700), [German Shepherd](/dogs-2026-11-08-0700), [Bulldog](/dogs-2026-11-09-0700), [Rottweiler](/dogs-2026-11-10-0700), [Doberman Pinscher](/dogs-2026-11-11-0700), [Pug](/dogs-2026-11-12-0700), [Shih Tzu](/dogs-2026-11-13-0700), [Boxer](/dogs-2026-11-14-0700), [Australian Shepherd](/dogs-2026-11-15-0700), [Pembroke Welsh Corgi](/dogs-2026-11-16-0700), [Great Dane](/dogs-2026-11-17-0700), [Saint Bernard](/dogs-2026-11-18-0700), [Bernese Mountain Dog](/dogs-2026-11-19-0700), [Shiba Inu](/dogs-2026-11-20-0700), [Samoyed](/dogs-2026-11-21-0700), and [Akita](/dogs-2026-11-22-0700). Start from [Types of dogs](/dogs).
- **Daily Star Wars guides**: Read a new Star Wars guide each day covering planets, droids, factions, starships, and the Force. The latest is [November 22](/star-wars-2026-11-22-1602). Start from the [Star Wars overview](/star-wars).
</Update>
