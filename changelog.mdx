<Update label="Nov 13, 2026" tags={["Added"]}>
## Glossary, dog breed profiles, and daily Star Wars guides

### New features

- **Glossary**: Look up five core terms on the new [glossary](/glossary) page.
- **Dog breed profiles**: Read a new breed profile each day, from [Chihuahua](/dogs-2026-11-03-0701) to [Shih Tzu](/dogs-2026-11-13-0700). Also covered: Beagle, Dachshund, Labrador Retriever, Poodle, German Shepherd, Bulldog, Rottweiler, Doberman Pinscher, and Pug. See the [Dogs overview](/dogs).
- **Daily Star Wars guides**: Browse a new Star Wars guide each day from [Nov 3](/star-wars-2026-11-03-1601) through [Nov 13](/star-wars-2026-11-13-1602). The latest covers bounty hunters, cantinas, and Force-sensitive creatures. See the [Star Wars overview](/star-wars).
</Update>
