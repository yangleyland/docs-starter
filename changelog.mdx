<Update label="Nov 16, 2026" tags={["Added"]}>
## Glossary and daily content pages

### New features

- **Glossary**: Look up core docs terms such as navigation, anchors, frontmatter, and snippets. See the [glossary](/glossary).
- **Daily dog breed pages**: A new breed profile is added each day. Nov 3-16 added Chihuahua, Beagle, Dachshund, Labrador Retriever, Poodle, German Shepherd, Bulldog, Rottweiler, Doberman Pinscher, Pug, Shih Tzu, Boxer, Australian Shepherd, and Pembroke Welsh Corgi. Start at [Types of dogs](/dogs).
- **Daily Star Wars pages**: A new page on factions, battles, and the Force is added each day. Start at the [Star Wars overview](/star-wars).
</Update>

<Update label="Nov 2, 2026" tags={["Added"]}>
## Projects section

### New features

- **Projects tab**: Browse project references from a new **Projects** tab in the navigation.
- **353labs**: Find guides for the C++ networking labs and programming assignments. See the [overview](/projects/353labs/overview), [labs](/projects/353labs/labs), [programming assignments](/projects/353labs/programming-assignments), [overlay network](/projects/353labs/overlay-network), and [shared libraries](/projects/353labs/shared-libraries).
- **arne-rizz**: Explore the multi-tab example site and its fictional API. See the [overview](/projects/arne-rizz/overview) and [Rizz API](/projects/arne-rizz/rizz-api).
</Update>
