## Glossary and daily guides

### New features

- **Glossary**: Look up five core docs terms, including `docs.json`, navigation, anchors, and frontmatter. See the [glossary](/glossary).
- **Daily dog breed profiles**: A new breed profile now publishes each day, from Chihuahua (Nov 3) to Saint Bernard (Nov 18). Browse the latest on [Types of dogs](/dogs) or open the [Saint Bernard profile](/dogs-2026-11-18-0700).
- **Daily Star Wars guides**: A new Star Wars guide now publishes each day. Start at the [Star Wars overview](/star-wars) or read the [latest guide](/star-wars-2026-11-18-1602).
</Update>
