## Glossary, daily breed profiles, and Star Wars guides

### New features

- **Glossary**: Look up core terms like docs.json, navigation, anchors, frontmatter, and snippets. See the [glossary](/glossary).
- **Daily dog breed profiles**: Read a new breed profile each day, covering temperament and origin. This week adds [Chihuahua](/dogs-2026-11-03-0701), [Beagle](/dogs-2026-11-04-0700), [Dachshund](/dogs-2026-11-05-0700), [Labrador Retriever](/dogs-2026-11-06-0700), [Poodle](/dogs-2026-11-07-0700), [German Shepherd](/dogs-2026-11-08-0700), [Bulldog](/dogs-2026-11-09-0700), [Rottweiler](/dogs-2026-11-10-0700), [Doberman Pinscher](/dogs-2026-11-11-0700), and [Pug](/dogs-2026-11-12-0700). Start from [Types of dogs](/dogs).
- **Daily Star Wars guides**: Explore planets, factions, and the Force in a new guide each day, from [Nov 3](/star-wars-2026-11-03-1601) to [Nov 12](/star-wars-2026-11-12-1602). Start from the [Star Wars overview](/star-wars).
</Update>
