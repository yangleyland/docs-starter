This page summarizes two repositories: `weatherapp.net` and `jwt-server`.

## weatherapp.net

`weatherapp.net` is a .NET MAUI app that shows current weather conditions. It targets Android, iOS, Mac Catalyst, and Windows, as configured in `WeatherApp.csproj`.

- `MainPage.xaml` defines the weather UI, including temperature, wind, humidity, pressure, cloudiness, sunrise, and sunset.
- `RestService.cs` calls the OpenWeatherMap API and deserializes the JSON response.
- `WeatherData.cs` maps the API response to C# types with Newtonsoft.Json.
- `Constants.cs` holds the OpenWeatherMap endpoint and API key settings.
- `FahrenheitToCelciusConverter.cs` and `LongToDateTimeConverter.cs` format values for display.

## jwt-server

`jwt-server` is a small Express server for testing JWT-based authentication with a Mintlify docs site. It signs tokens with the `jose` library.

- `server.js` serves a login page where you pick an email and groups. On submit, it signs an EdDSA JWT that expires after 8 hours. It then redirects to the docs site's `/login/jwt-callback` path with the token in the URL hash.
- `generate-keys.js` generates an EdDSA key pair. Run it with `npm run generate-keys`, as defined in `package.json`.
- `package.json` defines the `start` script, which runs `node server.js`.
